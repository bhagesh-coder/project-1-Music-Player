# project-1-Music-Player
A responsive Spotify-inspired music player built using HTML, CSS, and JavaScript. The application dynamically loads songs from local folders, displays albums with cover art and metadata, supports play/pause, next/previous track navigation, volume control, seek bar functionality, and active playlist highlighting. Album data is fetched from JSON files, providing a structured and scalable music library experience.

Features

Dynamic song loading from local directories
,Album-based music organization
,Play, pause, next, and previous controls
,Interactive seek bar and volume control
,Responsive user interface
,Active song and album highlighting
,Album metadata management using JSON

Technologies Used

1.HTML 5

2.CSS 3

3.JavaScript (ES6)

4.Fetch API

5.Audio API
